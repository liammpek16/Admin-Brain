## 🧩 Project schema (what each note holds)
You hand-set only **three** fields; the rest gets derived later.

| Field | Who sets it | Values |
|---|---|---|
| `health` | **you** | green · yellow · red · gray (not-started) |
| `priority` | **you** | high · med · low |
| `next` | **you** | one line: the single next action |
| `status` | you (for now) | active · planned · paused · blocked · done |
| `updated`, activity | *derived later* | from note edits + git |
| `repo` | you (optional) | git path/URL, so recency can be auto-derived |
